# Explanation
DandelionMMORPG is a Vanilla MMORPG themed server, created by [@NEXOmega](https://github.com/NEXOmega)
he is inspired by AresRPG Server, and a lot of other RPG-Themed games and Shows like Overlord.

The team is currently restrited to [@NEXOmega](https://github.com/NEXOmega)

## The `V 1`

Not released yet, but it's composed with a class system with a tree progression system, treasures to find, ressources to grind and dungeon to conquire.
A lot of Spell and a new Buffs system, with dangerous mobs and bosses.
